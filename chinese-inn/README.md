# Chinese Inn Restaurant Website

CSC1101 — Introduction to Web Development (HTML)

## Pages
- index.html — Home
- about.html — About
- menu.html — Menu
- gallery.html — Gallery
- contact.html — Contact

## Structure
- css/style.css — all styling and responsive media queries
- js/script.js — hamburger navigation, menu filter, live form validation and image slider
- images/ — local SVG artwork used by the site
- media/ — place the required kitchen-ambience MP3 here
- docs/ — optional documentation area

## How to run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Navigate through all five pages.
4. To test the audio requirement, add your own `kitchen-ambience.mp3` to `media/`.

## Coursework feature mapping
1. Hamburger navigation — mobile menu.
2. Menu filter — uses `data-category`, `querySelectorAll()` and `.hidden`.
3. Form validation — validates while typing and shows messages beside fields.
4. Image slider — index variable, previous/next buttons and current-slide display.
5. Dark mode was listed as optional in the plan and was not added so the four required interactive features remain clear.

## Important
The restaurant facts and prices in this student project are coursework content. Verify or replace contact details, chef details, address and menu information with the actual restaurant's information before publishing.
